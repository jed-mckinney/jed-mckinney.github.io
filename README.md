# jedmckinney.com

Source for Jed McKinney's personal website, built with
[Jekyll](https://jekyllrb.com) and hosted free on GitHub Pages.

- Editing guide: [HOW-TO-EDIT.md](HOW-TO-EDIT.md)
- Pages are the `.md` files in this folder; images are in `assets/img/`.
- `_layouts/default.html` is the page frame (header, menu, footer) and
  `assets/css/site.css` holds all styling. Both were written from scratch
  for this site.

Text, images, and the CV are © Jed McKinney unless credited otherwise.
